## **Overview**

Frenchie is C++ micro framework for development applications with graphical user interface (GUI). The project has been inspired by Dear ImGUI (https://github.com/ocornut/imgui) and Nuklear (https://github.com/vurtun/nuklear) libraries. Although those libraries propose simple and straightforward way to build GUI applications they are quite challenging to start with for those who does not have much background in computer graphics. The main aim of this projects is to implement a library that would be easy to understand and easy to use for begginers in computer graphics and that would provide more advanced build-in widgets and windows layout system.
